# Online Cinema

Coursework for the "Software Documentation" course.
Variant 17: an online cinema web application with subscriptions
(Free with ads / Premium without ads).

## Tech stack

- Python 3.12, FastAPI
- SQLAlchemy, SQLite
- HTML, CSS, JavaScript

## Project structure

- `app/` — backend (models, repositories, services, patterns, controllers)
- `frontend/` — web interface
- `docs/diagrams/` — UML diagrams
- `tests/` — automated tests
